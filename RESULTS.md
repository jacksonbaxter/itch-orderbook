# Results

Every results table of itch-orderbook. Generated by `scripts/results_table.py` from the files in [results/](results/), and never typed. `scripts/check.sh` fails if a table here differs from a fresh run, and `scripts/gate_numbers.py` holds every figure on this page to the file its line cites. The headline in [README.md](README.md) is a few of these rows; every verdict is here, failures included, and every run is in the last table, failed ones included.

## How to read them

The oracle and trade rows are the real book's. The SIMD kernel rows are the Mac's (NEON and, in node, WebAssembly SIMD128, each against scalar) and `debian`'s (Zen 1, SSSE3 and AVX2 against scalar), different experiments on different instruction sets; on both hosts the parser's default stays scalar. The harness-proof rows are the Phase 2 stub's, and say so. The book-design rows are from macOS, which cannot pin a thread, so none of them is a pinned figure and none stands for a Linux one, and from `debian`, pinned to core 4: the mapped runs with the top tracked, one set with hardware counters, and every design with the day in memory, published by P-0015 after earlier attempts at it were refused or stopped (the run log has each). The default arm is the paged index with flat levels, the fastest on both hosts.

T-INV-2 is strict, and it fails on real data: books cross while a symbol is halted or quoting, and for a moment after it resumes. That result stands, and no scoped version of it counts as a pass. A count of crossed books cannot tell a halt's leftovers from a broken book, so T-INV-3 exists as a second, separately named check, which the user approved after seeing real data: during normal trading, a book may only be crossed if the cross is left over from a halt and hasn't cleared yet, and any new cross is a failure. T-TRADE-3 compares odd lots on the SEC's published round-lot rule, chosen after a fixed lot and the directory's lot had each failed, and its odd-lot columns are not compared on dates that rule does not cover. T-TRADE-2 is compared with Nasdaq's CrossStats file on every Nasdaq day, and is not available on the BX day, since that file lists only Nasdaq's own crosses.
