# T-PARSE-1 to T-PARSE-3: the parse rate, on debian, 10302019

Generated by `scripts/parse_driver.py` from raw records that are not committed. Do not edit by hand.

Host: **debian**. Numbers from the two hosts are never mixed. The Mac is not measured.

Three passes over the whole day, held in memory, on one pinned thread, each as its target's source defines it (`bench/parse_passes.hpp`): the framing walk is itch-book's `scan()`, which reads each frame's length and type byte and counts it; the decode is the same loop with itch-book's ten types (S, R, A, F, E, C, X, D, U, P) decoded, adding the fields its Checksum handler adds; the strict decode runs `itch::decode()` on every frame and adds every field of every one of the 23 types. Each pass's rate is every framed message over its seconds; its GB/s is the whole file's bytes, length prefixes included, over the same seconds, in 10^9 bytes, as both sources count.

## Caveats

- T-PARSE-1 is a transcription of the work of itch-book's `scan()`, its `parse()` loop with a handler that takes nothing: per frame the length prefix, a stop at a zero-length frame, the type byte, the type's length looked up and compared, and one of three counters. The work is the same; what differs is the compiler and the host, the clock (rdtsc, one span a pass) and the figure the verdict is on (the median, not the best of 3).
- T-PARSE-2 is the same loop with the ten types itch-book's Checksum handler takes decoded and the fields it adds folded, and one add a message more than the source makes: the count of messages decoded, which bench_parse holds to the frame reader's count.
- T-PARSE-3: the strict decode reads the variant `itch::decode()` returns by a switch on its index, not `std::visit`, whose table of functions would put an indirect call in the loop. Lunary decoded the day memory-mapped; bench_parse, as itch-book does, reads a copy into anonymous memory before the warm-up, and every page of it was found resident before and after each timed pass; bench_parse counts no page faults. Lunary's bar is on 10302019, the day measured here.
- T-PARSE-1 and T-PARSE-2's bars were set on 12302019, itch-book's day, a day this run did not measure; this file gives their passes on 10302019 beside it; the days' sizes and each type's share of their messages, from scripts/data_manifest.json:
