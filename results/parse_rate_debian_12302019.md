## Caveats

- T-PARSE-1 is a transcription of the work of itch-book's `scan()`, its `parse()` loop with a handler that takes nothing: per frame the length prefix, a stop at a zero-length frame, the type byte, the type's length looked up and compared, and one of three counters. The work is the same; what differs is the compiler and the host, the clock (rdtsc, one span a pass) and the figure the verdict is on (the median, not the best of 3).
- T-PARSE-2 is the same loop with the ten types itch-book's Checksum handler takes decoded and the fields it adds folded, and one add a message more than the source makes: the count of messages decoded, which bench_parse holds to the frame reader's count.
- T-PARSE-3: the strict decode reads the variant `itch::decode()` returns by a switch on its index, not `std::visit`, whose table of functions would put an indirect call in the loop. Lunary decoded the day memory-mapped; bench_parse, as itch-book does, reads a copy into anonymous memory before the warm-up, and every page of it was found resident before and after each timed pass; bench_parse counts no page faults.
