## How this run reads the day

The day was mapped read-only, and each pass reads the mapping in place. After each message the book applied, the best bid and ask on its locate, price and shares, were read and compared with the last seen there: inside the throughput pass's time, outside each latency span. This is itch-book's T-BOOK-2 method, `itch-replay --book`: it maps the file and checks the best bid and ask, price and shares, after every book event.

## Book memory

T-BOOK-3. Read from phys_footprint from task_info(TASK_VM_INFO), in a process of its own that builds no other book first: once before the book is built, once after, every 1,048,576 messages of the untimed pass and at its end.
