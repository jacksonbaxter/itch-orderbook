## How this run reads the day

The day was read into anonymous memory before the warm-up and never mapped, so each pass reads a copy in RAM. Nothing read the top of book: each pass timed the book alone. This is itch-book's T-BOOK-1 method: its book_throughput reads the whole file into a buffer and times the book alone, with no top-of-book work.

## Book memory

T-BOOK-3. Read from phys_footprint from task_info(TASK_VM_INFO), in a process of its own that builds no other book first: once before the book is built, once after, every 1,048,576 messages of the untimed pass and at its end. The book's memory is the most charged at any reading less the reading before it was built. That is what the book itself takes, not the mapped file or the input copy, which are in the first reading, and not the latency samples, which that process never makes. itch-book's figure is peak RSS less the input buffer, the same quantity read another way. The ager's ballast is inside the figure: it holds 76.5 MiB of blocks at the end of the pass, and the pages of the blocks it freed stay charged.
