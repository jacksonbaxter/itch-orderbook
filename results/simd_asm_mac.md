## What was run

`bench/asm/` holds one extern "C" function an operation for each kernel, the kernel inlined into it inside its target region: `add_fields` (an Add Order into the 32-byte record of E2), `book_op_add` (an Add Order into the book's op), `field6` (E1's 6-byte field) and `batch4` (E5). Each is compiled with -S and its instructions counted. The scalar kernel is compiled under every compiler here, at -O2 and -O3, with the SLP vectorizer on and off; each vector kernel once, at the build's -O3. These are counts of compiler output: no clock or counter is read.
