## Book memory

T-BOOK-3. Read from RssAnon from /proc/self/status, in a process of its own that builds no other book first: once before the book is built, once after, every 1,048,576 messages of the untimed pass and at its end. The book's memory is the most charged at any reading less the reading before it was built. That is what the book itself takes, not the mapped file or the input copy, which are in the first reading, and not the latency samples, which that process never makes. itch-book's figure is peak RSS less the input buffer, the same quantity read another way.
